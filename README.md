# ThodDrop 2.0

Модуль ThodHUB для передачи файлов и текста между ПК и телефонами по локальной сети. Сервер, фоновый приём, привязка и интеграция с Windows реализованы на Rust. Интерфейс модуля и веб-приложение используют HTML, CSS и JavaScript.

## Первый запуск

1. Откройте ThodDrop в ThodHUB на компьютере, который будет ведущим. При первом запуске программа сохраняет его локальный IPv4-адрес. Порт по умолчанию — **47776**. В «Настройках» можно изменить адрес, подобрать свободный порт и управлять запуском при входе в Windows. Автозапуск включён по умолчанию. Фоновый процесс продолжает работать после закрытия вкладки и ThodHUB.
2. Для HTTPS откройте на ПК «Настройки → Сертификат» и отсканируйте телефоном QR-код. На iPhone установите профиль и включите полное доверие в «Основные → Об этом устройстве → Доверие сертификатам». На Android установите .cer как сертификат CA. Сверьте SHA-256 с отпечатком на ПК. Для доверенной Wi-Fi сети есть настройка «Открывать ThodDrop на телефоне без сертификата». Она включает локальный HTTP для телефона. QR-код привязки в этом режиме указывает на новый адрес.
3. На вкладке «Подключение» нажмите «Показать QR-код для телефона» и отсканируйте QR. На телефоне откроется привязка с уже заполненным кодом. Введите имя устройства. Ссылка с QR одноразовая и действует пять минут. Значок веб-приложения открывает постоянный адрес.
4. На вкладке «Подключение» другого компьютера нажмите «Показать код приглашения». На своём ПК выберите его в списке «Компьютеры в сети», нажмите «Подключиться» и введите пять символов. Для повторного поиска нажмите «Сканировать». Код действует пять минут, используется один раз и допускает восемь попыток. Полное приглашение также можно скопировать и вставить через «Ввести приглашение». Передавайте код через доверенный канал.

Компьютеры с ThodDrop 2.0.5 и новее обмениваются именами, идентификаторами и статусом устройств через ведущий ПК. Пользователи видят общий список на компьютерах и телефонах. Телефон привязывается один раз и продолжает открывать адрес своего ПК. Оба ПК должны быть включены для передачи между ними. Входящие можно скачать отдельно или ZIP-пакетом для нескольких вложений. В «Моих устройствах» и настройках можно забыть ведущий ПК. Сохранённые входящие остаются доступны.

ThodDrop открывается на вкладке «Передачи». Перетащите файлы или текст в окно либо выберите файлы через кнопку. Проценты отправки отображаются на каждом вложении. Файлы и текст из одной отправки показаны в общем сообщении. Нажмите на миниатюру, чтобы открыть изображение на весь экран. Для предпросмотра HEIC может потребоваться установленный в Windows кодек HEIF/HEVC. Новые файлы и текстовые заметки сохраняются в папку отправителя внутри `THODHUB_DATA_DIR/inbox`. Физическое удаление можно включить в диалоге подтверждения. Если iPhone подставляет букву вместо логотипа, в мобильном ThodDrop можно скачать отдельный профиль ярлыка с иконкой.

## Доступ к сети и настройки

- Сервер слушает выбранный частный IPv4-адрес, проверяет подсеть клиента и шифрует передачи по HTTPS. Страница первоначальной установки сертификата открывается с телефона по HTTP на отдельном локальном порту, указанном в «Настройках». На ней доступны только публичные файлы для установки сертификата. Административный интерфейс доступен через отдельное соединение на loopback с локальным ключом.
- Закрепите IP ведущего ПК в DHCP роутера, чтобы он оставался доступен по сохранённому адресу. После смены порта обновите ярлык телефона. На присоединённом ПК выберите «Обновить адрес ведущего ПК», чтобы сохранить привязку. Смена IP меняет область действия браузерной сессии, поэтому на телефоне понадобится привязка к новому IP.
- При запросе брандмауэра Windows разрешите доступ ThodDrop только для частных сетей. При ручном правиле ограничьте входящий TCP выбранным портом и локальной подсетью. Для поиска нужен mDNS в локальной сети. Переадресация порта на роутере для ThodDrop не требуется.
- Ключ сертификата и сохранённый ключ присоединённого ПК защищены Windows DPAPI. Для восстановления этих ключей нужен тот же профиль Windows с доступом к своим ключам DPAPI. Переход с версии 1.x требует новой привязки. Данные прежней версии остаются в её каталоге.
- За одну операцию можно выбрать много файлов. Предел одного файла — 2 ГБ. Ведущий сервер хранит до 10 000 входящих и до 20 ГБ учтённых данных. Файлы, оставленные на диске при удалении карточек, можно удалить вручную.

## Сборка пакета Windows x64

На машине сборки нужны Rust и инструменты упаковки из репозитория ThodHUB. Из корня ThodDrop выполните:

```powershell
pwsh -File scripts/build-release.ps1 -HubRoot D:/Projects/ThodPROD
```

Скрипт проверяет совпадение версий Cargo и манифеста, собирает переносимый EXE и создаёт ZIP с дескриптором релиза. В стандартной структуре `ThodHUB/projects/ThodDrop` параметр `-HubRoot` можно опустить. Сборка приложения не требует Node.js или .NET.
