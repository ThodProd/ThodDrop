# ThodDrop

Передача файлов, фото и буфера обмена между телефоном и ПК по домашней сети Wi-Fi
со сквозным шифрованием. На телефон ничего устанавливать не нужно. Работает внутри ThodHUB.

Основано на [Flitdrop](https://github.com/MrFrosas/flitdrop) (MrFrosas), лицензия FSL-1.1-ALv2.
Подробности изменений — в файле [NOTICE](NOTICE). Сборка: `npm install`, затем `node scripts/build-release.mjs`.
